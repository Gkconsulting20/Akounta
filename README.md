# Akounta Togo - Édition SaaS Commerciale

Plateforme complète de comptabilité vocale par IA avec modèle d'abonnement :
- Inscription & Connexion sécurisée par numéro de téléphone togolais + Code PIN
- Isolation stricte des données de chaque commerçant
- 14 jours d'essai gratuit offert
- Système d'abonnement mensuel (2 000 FCFA) et annuel (20 000 FCFA) via T-Money & Moov Money
- Blocage automatique en cas d'expiration d'abonnement (Code HTTP 402)
- Tenue de livre 100% vocale, bilan financier et export CSV
